$ dok tree

Tree view of compose projects, networks and volumes

Synopsis

dok tree [OPTIONS]

Description

Three trees: compose projects and their containers, networks with the IP of each attached container, and volumes with where each is mounted.

Network and volume membership is read from each container's own settings, since the list endpoints do not report it.

Options

--only <ONLY>
Show only this sectionpossible values: projects, networks, volumes
-a, --all
Include stopped containers

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok tree  # all three
$ dok tree --only networks  # one section
$ dok tree -a  # include stopped containers
