$ dok events

Live daemon event stream, colour-coded

Synopsis

dok events [OPTIONS]

Description

The daemon event stream, colour-coded by object type and action, with exit codes, signals and health changes picked out.

exec_* events fire on every docker exec and every healthcheck probe, and would drown the lifecycle events people watch for, so they are hidden unless --exec is given. --since and --until take timestamps or durations such as 2h.

Options

--since <SINCE>
Show events created since this timestamp or duration (e.g. 1h)
--until <UNTIL>
Stop at this timestamp instead of streaming forever
-T, --type <TYPE>
Restrict to these object types (container, image, volume, network, …)
-g, --grep <GREP>
Only lines containing this substring
--exec
Include exec_* events (docker exec and healthcheck probes)

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok events  # stream from now
$ dok events --since 2h  # replay the last two hours
$ dok events -T container,volume  # only these object types

Output

JSON output

$ dok events --json
{"action": "pull", "attributes": {"name": "ghcr.io/demo/api:1.9.2"}, "id": "ghcr.io/demo/api:1.9.2", "name": "ghcr.io/demo/api:1.9.2", "time": 1790502150, "type": "image"}
{"action": "create", "attributes": {"name": "demo-shop_default", "type": "bridge"}, "id": "5a4f9c1e7b20", "name": "demo-shop_default", "time": 1790502153, "type": "network"}

NDJSON: one object per line, flushed as it arrives. First two lines shown.
