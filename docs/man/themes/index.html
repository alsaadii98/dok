$ dok themes

List or preview themes

Synopsis

dok themes [OPTIONS]

Description

Lists the built-in themes and any defined in the config file, each with a row of swatches. A theme carries a palette of nine colour roles, a glyph set and a layout, so the ascii theme stays pure ASCII for CI logs and serial consoles.

--preview renders a sample table in every theme. --init writes a starter config to ~/.config/dok/config.toml.

Options

-p, --preview
Render a full sample of every theme
--init
Write a starter config file to ~/.config/dok/config.toml

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok themes  # list with swatches
$ dok themes --preview  # a sample table in each
$ dok ps --theme gruvbox  # use one for a single command
