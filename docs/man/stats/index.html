DOK-STATS(1)dok manualDOK-STATS(1)

$ dok stats

Live CPU / memory / IO dashboard

Synopsis

dok stats [OPTIONS] [CONTAINERS]...

Description

A live CPU, memory and IO dashboard. It is the one full-screen command: q quits and s cycles the sort.

It has no JSON form. With --json it exits with an error rather than drawing a dashboard into a pipe; use dok ps --json for a snapshot.

Arguments

[CONTAINERS]...
Limit to these containers

Options

--interval <INTERVAL>
Refresh interval in millisecondsdefault: 1500

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok stats  # every running container
$ dok stats api db --interval 500  # two containers, twice a second

JSON output

None. See the description above.

See also

dok-top(1), dok-ps(1), dok(7)
