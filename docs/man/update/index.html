$ dok update

Check for a newer dok and install it

Synopsis

dok update [OPTIONS]

Description

Checks GitHub for a newer release. A standalone binary is replaced in place, after its archive is verified against the release's .sha256. A packaged install is left alone and the package manager's own upgrade command is printed instead.

dok also checks at most once a day and prints one dim line after a command's output. It never does so when output is piped or --json is set. DOK_NO_UPDATE_CHECK=1 turns it off.

Options

--check
Only report what is available; do not install anything
-y, --yes
Install without asking

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok update --check  # report, install nothing
$ dok update  # install, after asking
$ dok update -y  # install without asking

See also

dok-uninstall(1), dok(7)
