$ dok images

List images with size and age gradients

Synopsis

dok images [OPTIONS]

Description

Images sorted by size, with size and age gradients. There is one row per tag, so an image carrying two tags appears twice; the total counts unique image ids so it agrees with docker system df.

Dangling images are marked reclaimable, and the last column counts the containers using each image.

Options

-a, --all
Include intermediate layers
--dangling
Only dangling (<none>) images
-s, --sort <SORT>
Sort keydefault: sizepossible values: size, age, name

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok images  # biggest first
$ dok images -s age  # newest first
$ dok images --dangling  # only untagged images
