$ dok inspect

Readable summary of a container's configuration and state

Synopsis

dok inspect [OPTIONS] <CONTAINERS>...

Description

The inspect JSON folded into identity, state, config, resources, network, mounts and labels. Privileged mode, added capabilities, OOM kills and failing healthchecks are called out in colour.

Environment variables appear only with --env. Values whose keys look like credentials (PASSWORD, SECRET, TOKEN, API_KEY and similar) are replaced by their length unless --show-secrets is given. --json masks exactly the same way.

Arguments

<CONTAINERS>...
Container names or ids

Options

-e, --env
Print environment variables
--show-secrets
Do not mask password/token-looking env values

Every command also takes the global options: --json, --color, --icons and --theme.

Examples

$ dok inspect api  # by name, service or id prefix
$ dok inspect api --env  # include environment variables
$ dok inspect api db  # several at once
